# Meubles Concept – Conceptor de Mobilă Online

O aplicație web interactivă pentru proiectarea și vizualizarea mobilierului, construită cu HTML, CSS și JavaScript vanilla.

## Funcționalități

- **Designer interactiv de camere** – plasează, mută și elimină piese de mobilier pe un plan 2D
- **Personalizare completă** – alege culori, materiale (lemn masiv, PAL, metal, stofă, piele) și dimensiuni
- **Catalog mobilier** – colecție filtrabilă pe categorii (living, dormitor, bucătărie, birou)
- **Export PNG** – descarcă planul camerei tale ca imagine
- **Design responsive** – funcționează pe desktop, tabletă și mobil
- **Suport touch** – drag & drop pe ecrane tactile

## Structura proiectului

```
├── index.html   # Pagina principală
├── styles.css   # Stiluri CSS responsive
├── app.js       # Logica JavaScript (designer, filtre, formulare)
└── README.md
```

## Utilizare

Deschide `index.html` direct în browser – nu necesită server sau dependențe externe.

```bash
# Sau pornește un server local simplu:
npx serve .
# apoi accesează http://localhost:3000
```
